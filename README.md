## 📦 Features

- 🔍 Scans and lists all active network adapters.
- 🚀 Allows quick DNS switching between:
  - Google DNS
  - Cloudflare DNS
  - OpenDNS
  - Quad9
  - CleanBrowsing
- 🧠 Interactive CLI with animated boot screen and colored output.
- 🛡️ Restores original DNS settings automatically on termination (`Ctrl+C`).
- 🛑 Admin privilege check with elevation prompt.
- 🎨 Custom stylized terminal output using ANSI escape codes.
